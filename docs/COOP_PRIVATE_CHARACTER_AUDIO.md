audio correction to source-derived character records. Full local and
same-machine paired qualification is still required. R4/R12 remain incomplete;
opposite rosters and unproved child-actor calls remain outside this boundary.

alias. All 18 applicable checks pass with nine stable voice leases, eight

across groups1/3. The resolver retains effective bank aliases, populated-program

SOUND provides the spatial actor. Calls whose a2 is exactly PLAYER route while
the private ordinary Zero body is projected in native phases0..3, outside local
presentation scope. Admission no longer depends on one ground-jump wrapper or
the shared defense-parts flag. Unproved child pointers retain their existing
path. This is a caller boundary, not proof that every record is reachable or
correct in native gameplay.

Raw group flags and record arguments reach the original SOUND calculation.
Its channel-disabled behavior remains original. Original out-of-range (-2) and
empty-record (-5) returns are preserved. Native RNG, suppression and priority
decisions remain in the game; zero KEYON calculations are valid, including an
opaque -1 result. The adapter does not force a voice or draw extra RNG.

The adapter saves all 2304 native driver bytes, 24 hardware priority bytes,
128 group-table bytes, the gate and current-record pointer. Both retained
group tables and private priorities are projected for one bounded uncharged
original SOUND call. Each original KEYON computes its own registers. All native
bytes are restored before any private DSP play. Calculated sample start and
ADSR must match the resolved original record. The resulting P2 priority bytes
persist separately from P1's table.

Private voices0,3,8,9,11,20,21,22,23 are reserved atomically under stable owner
tag `0x4D4D583650320001`. Ownership is independent of bank identity and active
state. Owner-scoped play permits an owned slot to change banks; foreign
reservations and active unreserved slots are refused. Fault/stop paths only
volume-zero and stop voices carrying this tag. Immutable banks30/31 retain
their existing byte-identity checks.

callers with exact s0=PLAYER and phase are redirected; phase2 includes the
original death-entry stops. Global FF executes original STOP once and then
stops leased private voices. No P1-table-derived mirrored character stop is
used. Unknown callers remain unverified. The previous image's successful
inactive STOP7 check does not qualify active STOP7 lifetime on this candidate.

canonical digest and save/load state. Readiness rejects live calculations,
pending outputs, foreign reservations and unbound epochs. The SDK private-SPU
wire separately preserves all stable 64-bit voice owners along with the DSP

required. Native memory cards remain a separate contract.
